# UAE Mattress Catalog — MCP server

Read-only MCP server (Streamable HTTP at `/mcp`) exposing an agent-readable catalog of mattresses sold in the UAE.
Data: public product information from the sellers' websites. Tools: `search_mattresses`, `get_product`, `compare_products`, `get_seller_policies`, `get_reviews`, `get_seller_reviews`, `list_filters`, `search`, `fetch`.

Run locally: `pip install -r mcp-server/requirements.txt && python mcp-server/server.py` (port from `$PORT`, default 8765). Public endpoint: `https://uae-mattress-mcp.onrender.com/mcp`.

Catalog snapshot 0.4.1 (Maps showroom ratings refreshed 2026-11-19). Server version **0.5.0**: search, product and compare results include a compact `social_proof` block in the first response — product rating and review count (or an explicit `reviews: none yet`), 1–2 short customer quotes (first name/initial only, date, rating, trimmed to ~200 characters; quotes that mention the shopper's fit filters are preferred), up to 2 original customer photo URLs, and the seller's Google Maps rating (average and total count across showrooms). The assistant is instructed to present rating, one quote and the seller rating in the first answer, and to offer more via `get_reviews`. Products with no reviews (including all Vispring and Colunex models in this snapshot) are labelled explicitly so the agent does not invent them. Review counts are used only as a price/relevance tie-break and never override a better name match or a cheaper same-score offer.

Base: two sellers — Askona Gulf (brand-direct: Askona, Sleep Professor, Grether & Wells) and The Mattress Store (authorized retailer: Englander, Vispring, Colunex). Each product has semantic fit attributes (weight range, sleep positions, motion isolation, couples, cooling, orthopedic, edge support, value-for-money) with provenance (`brand_stated` / `derived_rule` / `from_reviews`) — rules in `docs/fit_rules_ru.md`. Filters: `sleep_position`, `sleeper_weight_kg`, `min_rating`, `couple`, `motion_isolation`. Onboarding gaps for The Mattress Store: `docs/tms_onboarding_gaps_ru.md`.
